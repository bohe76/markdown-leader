# Security Policy

## Report a vulnerability privately

Report Markdown Leader vulnerabilities to `bohe76@gmail.com` instead of a public issue or comment. Use `Markdown Leader security report` as the subject and include:

- The affected extension, Chrome, and operating-system versions.
- Reproduction steps and the expected impact.
- A minimal Markdown sample or other reproduction material without personal information.
- The installation method: a local development build or a store installation.

Do not send passwords, tokens, or private documents. Remove personal paths and document contents from logs and screenshots. For a development build, include the commit identifier if you know it.

## Handling reports

Additional reproduction details and the timing of a fix or disclosure can be discussed after a report is received. This project does not promise response or fix deadlines, or a defined security-support period for older versions. Use the email address above; do not assume GitHub private vulnerability reporting is enabled.

See [Contributing](CONTRIBUTING.md) for general bugs and usage questions, and the [Privacy Policy](docs/operations/privacy_policy.md) for document, note, and external-resource data practices.
