# Markdown Leader

[English](README.md) · [한국어](README.ko.md)

로컬 Markdown 문서를 브라우저에서 읽고 검토하세요. 폴더 탐색·검색과 원본 문서에 저장하는 체크박스·메모를 제공합니다.

데스크톱 Chrome 121 이상을 대상으로 합니다. 현재 브라우저 검증은 Windows의 별도 Chromium 테스트 프로필을 중심으로 진행합니다. [Chrome 웹스토어](https://chromewebstore.google.com/detail/markdown-leader/mglmfpabbmcifhimdlembgchpaofbogm)에서 1.0.0을 설치할 수 있습니다. 이 소스 스냅샷은 다음 업데이트를 포함하며 현재 스토어 공개 버전과 다를 수 있습니다.

## 주요 기능

- 파일 URL, 확장 팝업, 파일·폴더 선택창 또는 드래그 앤 드롭으로 로컬 Markdown 열기
- 폴더 트리, 제목 목차, 파일명·문서 내용 검색
- 문서 탭, 탭 정렬·핀 고정, 최근 파일·즐겨찾기 다시 열기
- 표, 코드 강조, 상대경로 이미지·링크, 각주, 안내 박스, KaTeX 수식과 Mermaid 다이어그램
- 체크박스 변경과 선택한 텍스트에 메모 추가, 권한 허용 후 원본 파일 저장
- 밝게·어둡게·시스템 테마, 시스템·내장 Pretendard 글꼴, 글자 크기·읽기 폭 설정
- 외부 편집기의 변경을 활성 문서에 자동 반영하고 읽던 위치 유지
- Chrome 표시 언어가 한국어이면 한국어 UI, 그 외에는 영어 UI 적용. 원본 문서와 파일명 유지

MDX·MDC는 Markdown으로 읽으며 컴포넌트를 실행하지 않습니다. 읽기만 하면 원본 파일을 변경하지 않습니다. 일반 텍스트 편집기, 계정 기능, 열린 탭 전체의 세션 복원은 제공하지 않습니다.

## 로컬 빌드와 설치

[로컬 설치와 사용](docs/operations/local_install.md)의 개발 도구를 준비하고 프로젝트 루트에서 실행합니다.

```powershell
pnpm install --frozen-lockfile
pnpm build
```

1. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 선택하고 생성된 `dist` 폴더를 지정합니다.
3. 확장 상세 화면에서 **파일 URL에 대한 액세스 허용**을 켭니다.
4. Chrome으로 로컬 Markdown을 열거나 확장 팝업의 **리더 열기**를 선택합니다.

다시 빌드한 뒤에는 확장과 이미 열린 문서 탭을 새로고침합니다. 로컬 설치는 스토어 자동 업데이트를 받지 않습니다.

## 원본 파일과 개인정보

체크박스 변경과 메모 저장·수정·삭제에는 쓰기 권한이 필요합니다. 파일 URL로 연 문서는 파일 선택창에서 원본 파일을 연결해야 할 수 있습니다. 외부 변경이 감지되면 저장을 중단합니다. 다른 편집기에서 같은 파일을 동시에 저장하는 사용은 피하세요.

메모는 Markdown 끝의 HTML 주석에 저장합니다. 파일을 전달하면 메모도 함께 전달되며 원문에 접근할 수 있는 누구나 읽을 수 있습니다. 확장은 문서나 메모를 개발자 서버로 업로드하지 않습니다. 문서에 포함된 외부 이미지와 링크는 네트워크 요청을 만들 수 있습니다. 저장 위치·권한·삭제는 [개인정보처리방침](docs/operations/privacy_policy.md)을 참고하세요.
