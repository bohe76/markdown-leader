Markdown Leader Privacy Policy

Last updated: September 9, 2026. Applies to version 1.0.0.

Publisher: bohe76. Contact: bohe76@gmail.com.

Information handled

Markdown Leader reads the local documents the user opens, referenced images, directory listings, file names and paths to display and navigate documents. Directory entries are enumerated before the explorer filters supported Markdown types, so names of other file types may be encountered during enumeration.

Documents can contain arbitrary user-provided information. The extension does not classify that content for advertising, profiling or model training, or upload it to a developer server.

Reading preferences and recent/favorite entries, including names, paths, types and last-opened times, are kept in Chrome's local extension storage. File/directory access handles and relative paths used for reopening are kept in browser IndexedDB. The extension does not use Chrome's account sync storage.

Changes to original files

Reading alone does not change the original file. User-initiated checklist changes and note saves, edits or deletions update the original Markdown file after the necessary write access is granted. There is no general text editor or automatic AI editing service.

Notes, selected quotations, surrounding context, headings, creation times and identifiers are stored in a dedicated HTML comment at the end of the Markdown file. They travel with the file when shared and are readable by anyone with access to the file, even when hidden from rendered reading views. Notes are not encrypted private information.

Saving a document opened through a file URL may require the user to select the original file again. Chrome does not disclose the selected file's full path to the extension, so the user must check the displayed path and selected file. Detected external changes stop a save; the extension does not promise atomic coordination with every external program at every instant.

Network requests and sharing

The extension has no developer-operated document upload service, analytics, advertising, tracking tools or AI integration. Markdown text and notes are not uploaded to a developer server.

When a document references an external image, the browser may fetch it from that address. The image server receives the requested URL, IP address and ordinary browser request information. Cookies depend on Chrome settings and server policy. Clicking an external link navigates to its destination. Those requests follow addresses in the user's document and are subject to the destination's privacy practices. Local rendering does not mean that a document's external resources make no network requests.

Retention and deletion

The recent list contains up to 30 files and folders combined; it is limited by count, not an expiration date. New entries displace older recent entries. Favorites remain until unstarred. Unstarring does not remove an entry from the recent list if it is still among the latest 30.

Access handles support reopening recent and favorite items. Storage used from a file URL page and the standalone reader can be separated by origin. Uninstalling removes Chrome extension storage, but is not a guarantee that all host-page IndexedDB data is removed. Users can also clear the relevant site data in Chrome.

Checklist changes and notes remain in the original file until edited or deleted. Uninstalling the extension does not remove notes from those files. Open-document state and unsaved note drafts are kept in session memory, not a separate persistent full-document cache. Local browser-console errors may include file paths or original error details; the extension does not send them to a remote logging service.

Limited use and contact

Information is used only for document reading, navigation, review and user-requested saving. It is not sold or used for personalized advertising, lending or creditworthiness decisions. Markdown Leader's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Users may revoke permissions in Chrome; denied access prevents the relevant read/write operation. This policy and related notices will be updated if data practices change.
