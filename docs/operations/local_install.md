# 로컬 설치와 사용

Node.js 22, pnpm 10, Python 3.13을 사용한다. 제품 실행에는 Python이 필요하지 않다.

## 개발 환경 준비

프로젝트 루트에서 실행한다. Python은 최초 가상환경 생성 이후 프로젝트 .venv만 사용한다.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m playwright install chromium
pnpm install --frozen-lockfile
pnpm check
```

## 설치

1. `pnpm build`를 실행한다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켠다.
3. 압축해제된 확장 프로그램 로드로 프로젝트의 `dist`를 선택한다.
4. 확장 상세 화면에서 파일 URL에 대한 액세스 허용을 켠다.
5. 로컬 Markdown을 열거나 확장 팝업의 리더 열기를 누른다.

## 읽기

- 리본의 폴더 열기·파일 열기 버튼으로 새 자료를 선택한다. 파일 선택은 해당 파일만 읽고, 상대경로 이미지·다른 문서까지 읽으려면 폴더를 선택한다. 열기 동작은 읽기 권한만 요청하며, 체크박스·메모 저장은 아래 검토 절차를 따른다.
- 처음 실행한 독립 리더는 파일·목차·검색을 비활성으로 두고 본문 중앙에 열기와 드래그 앤 드롭 안내를 표시한다. 폴더 선택 뒤에는 목록에서 문서를 선택한다. 선택창 취소는 현재 자료를 유지한다.
- Chrome의 파일·폴더 읽기 허용창에 나오는 사본 안내는 읽기 권한의 범위를 설명한다. 제품은 사본 저장·업로드를 하지 않으며 Windows 보호 폴더는 Chrome 정책에 따라 선택이 제한될 수 있다.
- 최근 항목·즐겨찾기는 브라우저에 저장한다. 파일·폴더 핸들도 가능한 경우 보관하지만, 권한이나 핸들을 다시 사용할 수 없으면 항목을 열 때 원본 선택을 안내한다. 리더 안의 자동 새로고침은 선택한 핸들을 그대로 사용한다. 열린 탭 전체를 자동 복원하는 기능은 제공하지 않는다.
- 파일·폴더 연결을 사용할 수 없으면 공통 모달의 **다시 연결 / 목록에서 제거 / 취소**를 사용한다. 다시 연결은 옮긴 원본을 선택하는 동작이며, 열린 탭의 고정·즐겨찾기를 유지한다. 제거는 진입한 즐겨찾기 또는 최근 목록의 기록에만 적용하며 실제 파일과 열린 탭은 유지한다. 상세 범위는 [지원 기능](../../README.ko.md#주요-기능)을 따른다.
- 일반 알림은 우측 상단에 5초 동안 표시된다. 마우스를 올리거나 키보드 포커스를 두면 닫기 시간이 멈춘다. 연결 오류 알림이 사라진 뒤에도 탭의 **파일 연결 확인** 표식에서 복구를 시작할 수 있다.
- 다른 파일로 재연결된 메모 초안은 내용을 보존하고 저장을 차단한다. 내용을 복사한 뒤 해당 초안을 취소하고 새 메모로 작성한다. 폴더를 다시 연결하면 같은 상대 경로의 열린 하위 탭도 복구하며, 새 폴더에 없는 파일의 탭은 연결 표식을 유지한다.

- 첫 본문·제목·표·코드 강조와 사이드바는 CSS 및 저장된 테마·글꼴·글자 크기·읽기 폭이 적용된 상태로 표시한다. 설정 준비 중 원문이나 기본 스타일의 뷰어를 먼저 노출하지 않으며, Chrome이 이미 받은 원문을 다시 읽지 않는다. 폴더 탐색은 본문 표시 후 시작한다.
- 왼쪽 폴더 트리에서 폴더를 펼치고 문서를 선택한다.
- 폴더명 위의 T+A/Z 버튼은 이름순, 시계+N/O 버튼은 수정일순이다. 다른 버튼을 누르면 그 기준의 마지막 방향을 적용하고, 활성 버튼을 다시 누르면 방향을 뒤집는다. 폴더는 항상 파일보다 먼저 표시한다. 폴더 선택 API가 폴더 자체 수정 시각을 제공하지 않는 경우에는 폴더끼리 이름순을 유지하며 파일은 수정일로 정렬한다.
- 파일 목록과 폴더 검색에는 [지원 기능](../../README.ko.md#주요-기능)의 문서만 포함한다. `.txt`를 직접 여는 기존 동작은 유지하지만 목록에는 표시하지 않는다. MDX·MDC는 Markdown 부분을 읽으며 컴포넌트를 실행하지 않는다.
- 본문 표시 후 폴더 목록을 확인해 하위에도 대상 문서가 없는 폴더만 숨긴다. 확인 중이거나 읽기에 실패한 폴더는 유지한다. 자동 새로고침을 켜면 숨겨진 폴더도 다시 확인해 새 문서가 생겼을 때 표시한다. 꺼져 있으면 문서 새로고침이나 폴더 열기로 다시 확인한다. 한 번의 확인은 최대 2,000개 폴더 방문·64단계이며, 상한에 걸린 폴더는 숨기지 않는다.
- 제목 목차를 선택하면 해당 위치로 이동한다.
- HTML 주석 `<!-- ... -->`은 일반 본문에서 숨기고 코드 블록·인라인 코드·이스케이프한 표시는 보존한다. HTML 실행 차단은 유지한다.
- 본문의 단독 `[[TOC]]` 줄에는 문서 안 목차를 표시한다. 제목에 연결되며 사이드바 목차와 함께 사용할 수 있다.
- `> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]` 인용문을 안내 박스로 표시한다. 기본 제목은 UI 언어를 따르고 사용자가 쓴 제목은 그대로 둔다.
- `설명[^id]`와 `[^id]: 상세 설명`을 각주와 복귀 링크로 표시한다. 용어 다음 줄의 `: 정의`는 용어 정의 목록으로 표시한다.
- `$...$` 인라인 수식과 `$$...$$` 블록 수식은 처음에는 스타일이 적용된 원문으로 표시하고, 첫 콘텐츠 표시 후 KaTeX 엔진·전용 CSS·글꼴을 불러와 완성한다. 해당 자산은 내장되며 수식이 없는 문서에서는 요청하지 않는다. 잘못된 수식이나 로딩 실패는 원문과 안내를 남긴다. 코드 블록과 이스케이프한 달러 표시는 수식으로 해석하지 않는다.
- `mermaid` 코드 블록은 흐름도·시퀀스·ERD 등으로 표시하고 원문을 펼쳐 볼 수 있다. 렌더러는 첫 콘텐츠 표시 후 다이어그램이 있는 문서에서만 로드한다. 대기 중에는 기존 코드 스타일로 원문을 읽을 수 있다. 외부 리소스, Mermaid 설정 지시문·Front Matter, `@{...}` 노드 메타데이터(이미지·아이콘·새 shape 문법 포함), 50,000자 초과 입력은 원문으로 표시한다.
- 처리 중인 수식 원문과 완성된 수식의 내부 MathML·글리프, 다이어그램 SVG에는 검색 강조를 삽입하지 않는다. 다이어그램 원문에서 검색 결과로 이동하면 원문 영역을 펼친다.
- 사이드바 상단 제품명 오른쪽의 작은 버전은 현재 탭에 적용된 빌드 값이다. 확장을 업데이트한 뒤 이전 탭도 새로고침해야 새 버전이 표시된다.
- `:smile:`, `:+1:`, `:sparkles:` 같은 이모지 이름과 `19^th^`, `H~2~O`, `++추가++`, `==강조==`를 표시한다. 백틱으로 감싼 인라인 코드와 코드 블록의 문법은 원문 그대로 보인다.
- 문서 맨 앞의 `---`로 시작하고 `---` 또는 `...`로 닫힌 YAML Front Matter는 본문에서 숨긴다. 첫 내용이 `key:` 형태인 메타데이터 블록을 인식하며, 값을 읽기 설정에 적용하거나 YAML 객체로 실행하지 않는다. 닫는 구분자가 없으면 원문을 보존한다.
- 파일·목차 중 활성화한 탐색 모드에 따라 검색 버튼이 동작한다. 목차 모드의 현재 문서 찾기는 본문 위 여백 중앙에 표시한다. 검색어·결과 수·위/아래 꺾쇠·닫기는 검색창 안의 한 줄로 표시된다. 검색어를 입력하면 본문 일치 항목이 노란색, 현재 결과가 주황색으로 표시된다. 꺾쇠 버튼 또는 검색창에서 Shift+Enter/Enter, Shift+Tab/Tab으로 이동하고 닫기 버튼이나 Esc로 찾기 UI와 강조를 닫는다. 파일·목차·설정으로 전환해도 열린 찾기는 닫힌다. 검색 결과가 없으면 Tab은 기본 포커스 이동으로 동작한다.
- 파일 모드의 검색은 파일명과 문서 내용을 찾아 일치한 파일과 상위 폴더만 표시한다. 결과 파일명만 노란색으로 표시되고 상위 폴더는 강조 없이 펼쳐진다. 현재 문서의 파란색 표시가 우선하며, 문서를 열어도 검색어가 유지된다. 폴더 검색은 입력할 때 실행되므로 외부 파일 변경 후에는 검색어를 다시 입력해 결과를 갱신한다. 검색 범위·한도는 [지원 기능](../../README.ko.md#주요-기능)을 따른다.
- 자동 새로고침을 켜면 외부 편집기에서 저장한 내용을 반영한다. 기본 주기는 10초이며 0.5~600초로 설정한다. 이미 저장된 사용자 주기는 유지한다.
- 다른 탭으로 이동하거나 창을 최소화하면 자동 읽기를 쉬고, 문서로 돌아오면 즉시 갱신한다. 파일 읽기 한 건의 제한 시간은 갱신 주기와 별개인 15초다.
- 숨김·페이지 종료·문서 전환·자동 갱신 OFF 이전에 시작한 자동 읽기의 늦은 결과와 오류는 현재 화면에 적용하지 않는다. 복귀 때 이전 읽기가 아직 진행 중이면 중복 읽기를 만들지 않고, 해당 읽기가 끝난 뒤 다음 주기에 갱신한다.
- 읽기 설정에서 갱신 주기를 초 단위로 입력한다. 자동 갱신을 끄면 주기 입력도 비활성화된다.
- 테마 버튼으로 밝게·어둡게·시스템 중 하나를 고른다. 글자 크기와 읽기 폭 슬라이더 옆에는 현재 값이 표시된다.
- 저장된 값이 없을 때 기본 글꼴은 시스템 글꼴이며, Pretendard로 바꿀 수 있다. 시스템 글꼴은 `system-ui`를 사용하므로 macOS와 Windows에서 각 운영체제의 기본 UI 글꼴을 사용한다. 선택은 즉시 적용하며 `chrome.storage.local`의 `fontFamily`에 저장해 브라우저 재시작·다음 문서·확장 업데이트 후에도 유지한다. 웹페이지의 `localStorage`나 계정 동기화 저장소를 사용하지 않는다. 이전 버전에서 이미 저장된 Pretendard 값도 덮어쓰지 않는다. 첫 표시에서 Pretendard를 선택한 경우 내장 글꼴 준비까지 확인하고, 시스템 글꼴은 웹폰트를 요청하지 않는다.
- 글꼴 메뉴의 버튼과 펼친 목록은 [DESIGN.md](../../DESIGN.md)의 스타일을 따른다. Chrome 135 이상에서 테마별 배경·선택 체크·키보드 포커스를 적용하며, 이전 Chromium에서는 기본 선택 요소로 기능을 유지한다.
- 읽기 폭에서 A4 페이지를 선택하면 실제 페이지 경계를 보며 읽는다. 자유 폭으로 돌아가면 이전 슬라이더 값이 복원된다. 페이지 배치는 아래 PDF 미리보기와 공유한다. 범위와 상태는 [지원 기능](../../README.ko.md#주요-기능)을 기준으로 한다.
- 체크박스 변경과 메모 저장·수정·삭제는 원본에 반영한다. 일반 Markdown 편집 기능은 제공하지 않는다.
- 문서에 포함된 원격 이미지는 인터넷 연결이 필요할 수 있다.

## PDF 출력

1. 문서를 연 뒤 읽기 폭의 **A4 페이지**를 선택하면 용지 크기와 페이지 경계를 확인할 수 있다.
2. 리본의 프린터 아이콘 **PDF · A4 미리보기**를 누른다. 자유 폭에서도 바로 열 수 있으며, A4 화면에서 열면 이미 배치된 페이지를 그대로 사용한다.
3. 페이지 준비가 끝나면 미리보기를 확인하고 **PDF로 저장**을 누른다.
4. Chrome 인쇄 창에서 대상을 **PDF로 저장**, 용지를 **A4**, 배율을 **100%**, 여백을 **없음**으로 선택한다. **배경 그래픽**을 켜고 **머리글·바닥글**을 끈다.

긴 코드 줄은 A4 내용 폭에 맞춰 감싸고, 긴 표·코드는 다음 페이지로 이어진다. 표 머리글은 반복된다. 원본 코드의 들여쓰기와 내용은 유지하며, 복사 버튼과 스크롤바는 PDF에 포함하지 않는다. 이미지와 다이어그램은 비율을 유지해 용지 안에 배치한다. 미리보기의 테마·글꼴·글자 크기를 출력에도 적용한다.

미리보기는 출력 시점의 문서 사본이다. 열어둔 동안 원본이 바뀌면 닫고 다시 열어 최신 상태를 출력한다. 필요한 이미지·글꼴을 읽지 못하거나 페이지를 배치하지 못하면 오류를 표시하고 출력 버튼을 활성화하지 않는다. 인쇄 설정을 바꾸면 미리보기와 결과가 달라질 수 있다.

## 업데이트

코드 변경 후 `pnpm build`를 실행하고 Chrome 확장 관리에서 Markdown Leader의 새로고침 버튼을 누른다. 이미 열린 문서 탭도 한 번 새로고침한다.


## 개발 검증

`pnpm check`는 JavaScript 문법, Node 테스트, 문서 인덱스, TypeScript 및 개발 빌드를 검사한다. 별도 ESLint 검사는 없다. 문서 변경 후 `pnpm docs:index`, `pnpm docs:index:check`를 실행한다.

`pnpm python scripts/reader_library_smoke.py`는 별도 Chromium 프로필에서 최근 항목과 즐겨찾기를 검증한다. 자동화는 실제 OS 파일 선택창이나 모든 사용자 환경의 권한 동작을 증명하지 않는다. 관련 변경은 별도 테스트 프로필에서 실제 파일 선택과 허용·거부·취소 동작도 확인한다.

### 문서 탭

- 파일 열기와 탭 줄의 +는 파일 선택창을 연다. 선택을 취소하면 탭을 추가하지 않는다. 탐색기에서 문서를 클릭하면 내부 탭을 열고, 같은 URL 또는 파일 핸들로 확인된 문서는 기존 탭을 선택한다.
- 파일 URL로 먼저 연 문서와 파일 선택창으로 고른 핸들은 절대 경로를 대조할 수 없어 같은 파일도 별도 탭이 될 수 있다. 이름이나 내용만으로 추정 병합하지 않는다.
- 폴더 열기는 탐색기만 바꾸며 열린 문서는 유지한다. 문서 탭별로 스크롤 위치를 보존한다. 현재 활성 탭을 다시 누를 때는 불필요하게 읽지 않는다.
- 비활성 탭은 파일 참조·이름·스크롤 정보만 보관하고 본문 DOM·수식·이미지 URL·타이머를 유지하지 않는다. 다른 탭으로 바꾸면 이전 작업을 무효화한다. 다시 선택하면 원본을 한 번 읽고 자동 갱신 ON일 때 설정된 전체 주기로 다시 시작한다. OFF에서도 수동 탭 선택은 원본을 읽지만 자동 갱신은 시작하지 않는다.
- 탭 폭은 180px로 고정한다. 탭이 넘치면 좌우 버튼으로 탭 줄만 이동한다. +는 탭이 적으면 마지막 탭 옆에, 넘치면 오른쪽 끝에 표시된다. 탭 줄에서 좌우/Home/End는 포커스만 이동하고 Enter/Space로 선택하며 Delete로 닫는다. X는 활성·hover·focus 탭에서 표시된다.
- 탭을 드래그해 순서를 바꾼다. 고정 탭은 앞에 유지하며 고정 탭끼리, 일반 탭끼리 정렬한다. 넘친 탭은 줄 가장자리에서 드래그하면 스크롤한다.
- 새로 고정한 탭은 항상 맨 앞에 놓이고 탭 줄은 맨 왼쪽으로 이동한다. 해제한 탭은 마지막 고정 탭 바로 뒤로 이동하며 탭 줄 스크롤은 유지한다. 핀 토글은 현재 문서를 바꾸지 않는다.
- 탭의 핀·별 버튼은 토글로 동작한다. 비활성은 연한 회색, 활성은 테마에 맞는 진한 대비로 표시한다. 핀을 켠 탭을 닫을 때는 제품 확인 모달을 표시한다. 즐겨찾기만 켠 탭은 바로 닫을 수 있고 즐겨찾기 목록에는 남는다.
- 문서 전환 중에는 카드 높이를 유지한 빈 문서를 표시하고, 150ms 이상 걸릴 때만 정적인 스켈레톤을 보여준다. 이전 본문은 보관하지 않는다.
- 본문과 탭은 연결되어 보이며 본문 위치·폭은 유지된다. 현재 문서 찾기는 탭 위에 떠서 표시하고 X/Esc로 닫는다.
- 마지막 문서 탭을 닫으면 시작 안내로 돌아가고 문서 갱신은 멈춘다. 선택한 탐색 폴더의 권한은 다른 문서를 열 수 있도록 유지한다. 리더 페이지를 새로고침하면 내부 탭은 초기화된다.

### 패널과 최근 항목·즐겨찾기

- 리본의 패널 접기·펼치기 버튼으로 왼쪽 탐색·설정을 숨기거나 다시 연다. 로고와 리본은 같은 자리에 남고 제품명·버전은 패널과 함께 접힌다. 접힘 상태는 저장한다.
- 리본의 최근 항목·즐겨찾기를 누르면 왼쪽 패널에서 해당 목록을 보여준다. 최근 항목은 파일·폴더 합산 30개이며, 같은 항목을 다시 열면 맨 위로 이동한다.
- 즐겨찾기는 탭의 별로 추가·해제하며, 목록에서도 해제할 수 있다. 최근 목록에서 밀려나도 즐겨찾기는 유지한다. 파일 항목은 문서를 열고 폴더 항목은 탐색 폴더를 바꾼다.
- 파일 URL은 저장된 주소로 다시 연다. 선택창으로 연결한 파일·폴더는 저장된 핸들의 읽기 권한을 확인하며, 사용할 수 없으면 원본을 다시 선택한다. 파일명만 같은 다른 파일을 선택하지 않도록 안내된 경로를 확인한다.
- 최근 항목은 작업 공간 저장이나 열린 탭·고정 상태의 세션 복원을 대신하지 않는다.

### 체크박스와 메모 검토

- 본문의 체크박스를 클릭하면 해당 항목의 `[ ]` 또는 `[x]`를 원본에 반영한다. 저장 실패 시 체크 상태를 되돌리고 오류를 표시한다.
- 본문 텍스트를 드래그한 뒤 마우스를 놓으면 해당 위치 아래 중앙에 **메모 추가** 버튼이 나타난다. 양방향 드래그 모두 놓은 위치를 따른다. 휠을 움직이면 선택은 유지하면서 버튼만 숨긴다. 버튼을 눌러 우측 패널에서 내용을 작성하고 저장한다. 드래그 중이거나 마우스를 올리기만 하거나 우클릭했을 때는 추가 버튼을 표시하지 않는다.
- 메모 번호는 선택한 범위 끝의 오른쪽 위에 표시하며, 우측 메모 패널이 덮어도 위치를 옮기지 않는다.
- 메모는 본문 위치 순서의 숫자로 표시한다. 본문의 원형 번호나 메모 카드를 누르면 해당 범위를 강조하고, 다시 누르면 강조를 해제한다. 번호는 저장하지 않으며 메모 삭제·본문 위치 변경 뒤 다시 계산된다.
- 메모 카드에서 인용한 원문을 확인하고 대상 위치로 이동하거나 메모를 수정·삭제한다. 인용문은 한 줄로 표시하며 길면 말줄임표로 줄인다. 원문이 바뀌어 대상을 찾을 수 없으면 본문 번호·강조 없이 `대상 문구를 찾을 수 없음` 구역에 메모를 보존한다.
- 리본의 메모 버튼이나 패널의 닫기로 우측 패널을 열고 닫는다. 패널은 본문 위에 겹치며 읽기 폭·본문 배치를 바꾸지 않는다. 패널 밖 본문은 어둡게 덮지 않고 계속 조작할 수 있다.
- 메모는 문서 끝의 `MARKDOWN-LEADER:NOTES` HTML 주석 구역에 인용문·주변 문맥·메모 내용과 함께 저장한다. 일반 Markdown 렌더링에서는 숨겨지고, MD 원본을 전달하면 메모도 함께 전달된다. 수신자는 원문을 읽는 AI에 메모 검토를 요청하거나 이 리더로 메모를 볼 수 있다. AI를 자동 호출하지 않는다.
- 원본 쓰기는 체크박스와 메모로 제한한다. 필요한 쓰기 권한은 저장할 때 요청한다. 파일 URL로 열어 쓰기 핸들이 없는 문서는 안내 모달 후 파일 선택창에서 **현재 원본 파일**을 연결해야 한다. 취소하거나 권한을 허용하지 않으면 저장하지 않는다.
- 저장 전 원본과 현재 읽은 내용을 비교한다. 외부 변경이나 문서 전환으로 저장 대상이 달라진 경우 저장을 중단하므로, 최신 문서를 확인한 뒤 다시 검토한다. 메모 구역의 형식을 해석할 수 없으면 덮어쓰지 않는다. 다른 편집기와 동시에 저장하는 사용은 피한다.

### 단축키

- `Alt+R`: 자동 새로고침 켜기·끄기.
- `Alt+T`: 밝게·어둡게 테마 전환.
- 단축키 할당은 `chrome://extensions/shortcuts`에서 확인한다.
